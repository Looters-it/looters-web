# Map fonts

Font files MapLibre uses to draw text on the map (style property `font-faces`), so that
labels use the same typefaces as the interface and need no third-party glyph server.

- Sorts Mill Goudy Regular: municipality names. SIL Open Font License 1.1.
- Alfa Slab One Regular: empire names. SIL Open Font License 1.1.

Source: https://github.com/google/fonts (`ofl/sortsmillgoudy`, `ofl/alfaslabone`).
